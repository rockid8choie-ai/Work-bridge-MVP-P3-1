# 01. 프로젝트 주제 및 배경

> 코드잇 부트캠프 실무 프로젝트 P(3-1) 과제 가이드 원문. 2026-10-13 사용자 전달분을 그대로 옮김.

## 1. 프로젝트 배경 및 주제

이 프로젝트는 의뢰인과 프리랜서를 안전하게 연결하는 외주 매칭 플랫폼(WorkBridge) MVP를 풀스택 JavaScript로 직접 설계 및 구현하는 것을 목표로 합니다. 의뢰인은 프로젝트를 등록하고 적합한 프리랜서를 찾을 수 있으며, 프리랜서는 본인의 경력과 포트폴리오를 등록해 원하는 프로젝트에 지원할 수 있습니다. 플랫폼은 탐색, 지원, 계약과 결제까지 외주의 전체 라이프사이클을 안전하게 다루며, 에스크로 결제와 상호 평가를 통해 거래 신뢰를 확보합니다.

이를 통해 다양한 비즈니스에서 보편적으로 사용되는 기능 모듈(유저 관리, 결제, 알림, 검색/필터, OAuth, PG, Open API 등)을 한 서비스 안에서 종합적으로 구현해보고, 향후 유사한 비즈니스 도메인에서 빠르게 응용할 수 있는 토대를 마련합니다.

## 2. 프로젝트 목표

이번 프로젝트를 통해 실제 비즈니스 요구사항을 풀스택 JavaScript로 구현하는 전 과정을 경험하며, MVP 정의부터 배포 및 운영에 이르는 제품 개발 사이클을 체득합니다. 단, 본 프로젝트는 MVP 완성도와 보편적 기능 모듈 구현 경험에 초점을 둡니다. 아키텍처 고도화, 성능 최적화, 인프라 설계 등 엔지니어링 심화 역량에 시간을 과도하게 투자하지 않도록 주의해 주세요. 작지만 완전한 제품을 완성하고, 점진적으로 기능을 추가하는 애자일 사이클을 경험하는 것이 우선 목표입니다.

이를 통해 다음과 같은 학습 성과를 기대합니다.

- 실제 비즈니스 요구사항을 분석해 MVP 범위를 설정하고 데이터 모델로 표현할 수 있다
- 프론트엔드와 백엔드를 직접 연결해 완성도 있는 풀스택 웹 애플리케이션을 구현할 수 있다
- OAuth, PG, LLM 등 외부 Open API를 비즈니스 흐름에 안전하게 통합할 수 있다
- 스프린트 단위로 협업하고, 칸반 보드와 회고를 통해 애자일 개발 프로세스를 경험한다
- 완성된 서비스를 직접 배포하고 운영 환경에서 동작시킬 수 있다

## 3. 프로젝트를 통해 얻을 수 있는 역량

### 지식 (Knowledge)

- **풀스택 웹 개발 프로세스 이해** — 요구사항 분석 → 데이터 모델링 → API 설계 → 클라이언트/서버 구현 → 배포로 이어지는 제품 개발 전 과정에 대한 이론과 실제 적용 방법 습득
- **비즈니스 도메인 기반 데이터 모델링** — 외주 플랫폼 도메인을 ERD로 표현하고, 이를 관계형 DB 스키마로 옮기는 모델링 방법론 학습
- **Open API 활용 패턴** — OAuth 2.0 인증 코드 플로우, PG 결제 콜백/검증, LLM API 프롬프트 엔지니어링 및 구조화된 응답 처리 등 외부 서비스 연동 패턴 학습
- **애자일 협업 프로세스** — 스프린트 단위 작업 분할, 칸반 보드 운영, 코드 리뷰 등 실제 팀 개발 환경에서의 협업 구조 학습

### 기술 (Skills)

- **프론트엔드 구현 기술** — SPA 설계, 라우팅, 상태 관리, API 통신 계층 구현 능력 습득
- **백엔드 구현 기술** — RESTful API 설계, 인증 처리, 미들웨어 구성, 트랜잭션 및 부수 효과(자동 거절, 일괄 처리, 알림 생성 등) 처리 기술 습득
- **Open API 연동 기술** — LLM API 기반 구조화된 응답 처리, PG 결제 검증, 소셜 로그인 인증 플로우 구현 능력 습득
- **협업 및 배포 기술** — 브랜치 전략 기반 협업, PR 리뷰, 칸반 보드 운영, 자동 배포 파이프라인 구성 기술 습득

### 태도 (Attitude)

- **개발 협업 프로세스 전반에 대한 이해와 커뮤니케이션 역량** — 스프린트 단위 협업, PR 기반 코드 리뷰, 회고를 통해 다른 개발자와 함께 일하는 방식에 대한 감각 습득
- **Open API 활용 경험을 토대로 한 비즈니스 기회 탐색 태도** — 외부 서비스(인증, 결제, LLM 등)를 조합해 빠르게 가치 있는 제품을 만들 수 있다는 자신감 확보
