## 0. 한 줄 원칙

**"BFS 네이비 위에 블루 한 줄."** 어두운 네이비 히어로가 첫인상을 만들고, 본문은 흰 카드가 떠 있는 옅은 캔버스, 블루는 강조·링크·그라디언트에만 쓴다. 글자는 굵고 크고 촘촘하게(800 웨이트, 자간 −3.5%), 모서리는 크게(카드 20px, 버튼은 알약), 움직임은 호버에서 2px 떠오르는 정도로만.

## 1. 왜 이렇게 정했나 — 2026 트렌드 중 가져온 것 / 버린 것

| 가져온 것 | 근거 | 우리 적용 |
|---|---|---|
| **다크 히어로 + 글로우** | Linear·Vercel·Stripe 류 B2B SaaS 랜딩의 표준. 밝은 본문과 대비가 커서 "제품"처럼 보인다 | 히어로·CTA 밴드만 네이비(`bg-night`). 나머지는 밝게 |
| **큰 볼드 헤드라인 + 그라디언트 강조 1곳** | 한 문장만 기억시키는 잡스식 메시지. 그라디언트는 핵심어 1곳만 | `text-display` 64/800/−0.035em, `text-gradient`는 "‘계약 범위’"에만 |
| **커맨드바형 입력** | Thumbtack·Angi 가 검색창을 "문제 서술" 입력으로 바꿈(docs/08 2장) | 알약형 흰 바 + 돋보기 + 그라디언트 버튼 |
| **벤토 그리드 + 제품 모형** | 기능을 말로 설명하지 않고 작은 UI 모형으로 보여줌 | 작동 방식 3장(문제 입력 → 항목 목록 → 단계별 정산 바) |
| **글래스 고정 헤더** | 스크롤해도 내비가 남고, 배경이 비쳐 가벼움 | 앱 셸 `glass sticky` |
| **카드 호버 리프트** | 클릭 가능한 것만 떠오르게 — 모션은 신호 | `card-hover` −2px + shadow-2 |
| **아이콘은 선 2px** | Lucide 계열 미니멀 선 아이콘이 표준 | 카테고리 8종 인라인 SVG, 라이브러리 없음 |

| 버린 것 | 이유 |
|---|---|
| 가는(300) 디스플레이 | 10/26 배포 후 "신경 안 쓴 것 같다" — 한글에서 가는 큰 글씨는 힘이 없다 |
| 회색 CTA 단색 | 눌러야 할 곳이 안 보였다. 주 CTA는 네이비, 히어로 CTA는 블루 그라디언트 |
| 다크 모드 | MVP 범위 밖. 시연 환경마다 색이 달라지는 걸 막으려 `color-scheme: light` 고정 |
| 애니메이션 라이브러리 | 등장 모션(`rise`) 히어로 1곳만, CSS 키프레임으로 충분 |

## 3. 글자

폰트는 **Pretendard Variable** 한 종(웹 산출물 공통 규칙). 클래스 하나가 크기·행간·웨이트·자간을 같이 고정한다.

| 클래스 | 크기 / 행간 | 웨이트 | 자간 | 쓰는 곳 |
|---|---|---|---|---|
| `text-display` | 64 / 1.05 | 800 | −0.035em | 히어로 헤드라인(데스크톱) |
| `text-display-sm` | 40 / 1.08 | 800 | −0.03em | 히어로(모바일)·CTA 밴드·큰 숫자 |
| `text-h1` | 36 / 1.15 | 800 | −0.025em | 섹션 제목·상세 제목 |
| `text-h2` | 26 / 1.25 | 700 | −0.02em | 앱 화면 제목 |
| `text-h3` | 18 / 1.35 | 700 | −0.015em | 카드 제목·폼 섹션 |
| `text-body-lg` | 18 / 1.65 | 400 | — | 히어로 설명 |
| `text-body` | 16 / 1.65 | 400 | — | 본문 |
| `text-label` | 14 / 1.45 | 500 | — | 폼 라벨·내비 |
| `text-caption` | 12 / 1.4 | 500 | — | 출처·보조 |
| `text-eyebrow` | 12 / 1 | 700 | +0.08em, 대문자 | 섹션 위 작은 영문 라벨 |

- 숫자는 `tracking-tight` + 700 이상. 예산은 카드에서 제목 다음으로 크게(20px).
- 문장은 쉬운 말로. "프로젝트"는 쓰지 않는다(5장 용어 참고).

## 6. 화면 구성

**홈 (`app/page.tsx`)** — 위에서부터
1. 투명 헤더(로고 흰색 녹아웃 + 로그인/회원가입 고스트 버튼)
2. 히어로(네이비): 라벨 알약 → 헤드라인 2줄("가격보다 먼저, / ‘계약 범위’를 합의합니다.") → 설명 2문장 → 커맨드바 → 카테고리 칩 7개 → 숫자 한 줄
3. 작동 방식(흰 배경): eyebrow → h1 → 벤토 3장(01 문제 입력 모형 · 02 작업 항목 목록 모형 · 03 단계별 정산 바)
4. 비교(캔버스): "입찰은 가격을 정합니다. 우리는 범위를 정합니다." → 2열 카드(일반 플랫폼 − / 우리 ✓, 우리 쪽은 블루 링) → 숫자 카드 3장 + 출처
5. 지금 모집 중인 공사: 실제 데이터 3장(`open` 최신순) + 전체 보기
6. CTA 밴드(네이비, 28px 패널): "오늘 올린 공사, 내일 범위가 정해집니다." + 건물주/전문가 버튼
7. 푸터: 로고(작게) · 링크 4개 · ©

**앱 셸 (`app/(app)/layout.tsx`)** — 캔버스 배경, 글래스 고정 헤더(로고 · 메뉴 알약 · 알림 배지 · 아바타 알약 · 로그아웃), 본문 1024px.

**목록** — 제목+건수 / 공사 올리기(건물주) → 필터 카드(검색 인풋+네이비 버튼, select 5개) → 카드 2열 그리드 → 알약 페이지네이션.

**상세·폼·프로필** — 전부 `card p-6 sm:p-8` 한 장 위에. 상세의 예산·마감·지원 3칸은 카드 안 `canvas-50` 패널.

**인증** — 캔버스 배경 가운데 로고(크게) + 한 줄 + 카드 1장(`shadow-2`).

## 6-1. 풍성함 레이어 (10/26 추가 — "단조롭다, 빌딩왕은 화려하다" 피드백)

빌딩왕은 **검정 바탕 + 금색 + 화면 전체를 덮는 사진(영상) 1장**으로 화려함을 만든다. 우리는 사진을 쓰지 않고(라이선스·건물 실사 확보 전) 아래 5가지로 같은 밀도를 만든다. 전부 마크업·CSS·SVG라 로딩 비용이 없다.

| 장치 | 파일 | 규칙 |
|---|---|---|
| **떠 있는 제품 카드 3장** | `components/HeroVisual.tsx` | 범위표(메인) · 승인 요청 토스트 · 단계별 정산. 각각 6~8초 주기로 8px 부유, 기울기 −1.5°/2°/1°. 수치는 예시이며 "합계 · 예시"로 표기. `lg` 이상에서만 표시 |
| **움직이는 글로우** | `.glow-a` `.glow-b` | 블루 블러 원 2개가 20·24초 주기로 천천히 이동·확대. 히어로·숫자 밴드 |
| **건물 스카이라인** | `components/Skyline.tsx` | 결정적 배열 29동, 블루 그라디언트 + 창문 패턴. 히어로 하단 180~240px, 장식(aria-hidden) |
| **흐르는 띠** | `.marquee` | 카테고리 7개 + 약속 문구 4개, 36초 1회전, 호버 시 정지. 히어로 바로 아래 |
| **카테고리 타일 8장** | `tile` 유틸 | 그라디언트 아이콘 원(호버 시 1.1배) + 이름 + 증상 힌트. 호버 시 블루 링 |
| **숫자 카운터 밴드** | `components/Counter.tsx` | 네이비 풀블리드, 72px 그라디언트 숫자. 화면 진입 시 0→값 1.4초(ease-out cubic). SSR 은 최종값, reduced-motion 은 즉시 표시 |

**모션 총량 규칙** — 동시에 움직이는 것은 화면당 최대 3종(글로우·부유 카드·띠). 그 외 모션은 호버 응답뿐. `prefers-reduced-motion` 이면 전부 끈다.

홈 순서(갱신): 히어로(2열: 카피+커맨드바 / 제품 카드) → 띠 → 작동 방식 3장 → 카테고리 타일 8장 → 숫자 밴드(네이비) → 비교 2열 → 모집 중 공사 → CTA 밴드 → 푸터.

## 7. 하지 말 것

- 블루 채움 버튼을 앱 안에서 쓰지 않는다(히어로·CTA 밴드 전용).
- 카드 안에 카드 안에 카드 — 2단까지만(카드 → canvas 패널).
- 그라디언트 글자는 페이지당 1곳.
- 로고 글자를 폰트로 다시 그리지 않는다. 워드마크 비율 변경 금지.
- 새 색 추가 금지. 필요하면 이 문서부터 고친다.
- 영문 eyebrow 는 섹션 라벨에만, 본문은 한국어 쉬운 말.
