## 2. 2026 마켓플레이스 공통 패턴 3개 (전부 채택)

1. **진입점 = 검색창이 아니라 "문제 서술" 인풋.** Thumbtack(텍스트·사진·음성 → 후속 질문 → scope → 프로), Angi AI Helper, Upwork AI-native 홈. 우리 0단계 자연어 입력(`docs/05` 흐름 1번)이 정확히 이 패턴이다. 히어로는 **서술 인풋 하나 + 인기 카테고리 chips**.
2. **프로 카드의 "신뢰 스택" 표준.** `★평점 (리뷰수)` · 검증 배지(라이선스/신원) · 응답성(1시간 내 응답) · 실적 볼륨(완료 N건) · 티어 배지. 배지는 **아바타 밖 텍스트 줄**에(Fiverr 2025-03 이 신원인증 아이콘과 혼동돼 분리). 보장 배너는 **금액 명시**(Taskprotect 최대 $1,000).
3. **비주얼 수렴.** 화이트 캔버스 + near-black 텍스트(`#222` 계열, 순수 검정 금지) + 액센트 1색을 "구두점"으로만(Fiverr·Airbnb 모두 액센트를 기본 CTA 채움으로 쓰지 말라 명시) + 저채도 회색 + radius 8(컨트롤)/12~16(카드)/pill + 플랫 또는 쉐도우 1단계 + 산세리프 1종(헤딩 500~700, 자간 −0.01~−0.02em). 컨테이너 1200px, 4px 베이스, 섹션 간격 40~64px.

## 3. 리더 차별화 패턴 — 우리가 가장 잘 먹을 수 있는 것

- **가격 선노출 깊이.** TaskRabbit 은 카테고리 타일에 시작가, 프로필에 수수료 포함 시간당 요금, 결제 전 수수료 분해. HomeAdvisor 비용가이드는 **"Normal Range $965–$3,089 · national average $2,022" + 면적별 표 + 데이터 출처("2M reported costs")**. → 우리 공정표 행에 **"일반 범위 ₩X–₩Y · 근거"** 를 그대로 쓴다. 공정 사전의 low~high 가 바로 이 범위다.
- **scope 분해가 제품 중심.** "카테고리 → 리스트"가 아니라 **"문제 → 작업항목들 → 항목별 프로/견적"**. 우리 공정표를 **체크리스트 카드(공정명·범위·추정 범위·근거)** 로 보여주고 각 항목에 상태를 붙인다.
- **온기 레이어.** Upwork(세리프 혼용 + 그라디언트), Airbnb(3D 아이콘). 우리는 폰트 교체 없이 **디스플레이 300 vs 본문 600~700 웨이트 대비** 한 곳 + 모션 1~2곳으로 충분.

## 4. 우리 토큰 (Tailwind 4 `@theme`)

현재 slate(파란 틴트 회색) → **저채도 뉴트럴**(Thumbtack `#2b2d2f·#676d73·#dddee1·#f5f6f6`, Airbnb `#222·#6a6a6a·#ddd·#f2f2f2`)로 바꾼다. 건물·안전 연상으로 **블루 액센트 1색** 유지하되 CTA 채움은 near-black 로.

```css
@theme inline {
  --font-sans: "Pretendard Variable", Pretendard, -apple-system, sans-serif;

  /* 뉴트럴 (Thumbtack gray + Airbnb 절충) */
  --color-ink-900: #222325;   /* 본문·헤딩. 순수 검정 금지 */
  --color-ink-700: #4c4e52;
  --color-ink-500: #676d73;   /* 보조 텍스트 */
  --color-ink-400: #83878d;   /* 플레이스홀더 */
  --color-line-200: #dddee1;  /* 헤어라인·카드 보더 */
  --color-line-100: #eeeff2;
  --color-canvas-50: #f5f6f6; /* 섹션 배경 */
  --color-paper: #ffffff;

  /* 액센트: 구두점으로만 (링크·선택·배지·포커스) */
  --color-accent-600: #0175a3;  /* Thumbtack blue-700 — 텍스트 대비용 */
  --color-accent-500: #009fd9;  /* Thumbtack blue-600 */
  --color-accent-50:  #e6f6fc;

  /* 상태 */
  --color-ok-600: #16855b;      /* 승인·완료 */
  --color-warn-500: #eab308;    /* 확인 필요 (AI 범위 위반 플래그) */
  --color-danger-600: #dc2626;

  /* 형태 */
  --radius-control: 8px;   /* 버튼·인풋 */
  --radius-card: 12px;     /* 카드 */
  --radius-panel: 16px;    /* 큰 패널·모달 */
  --shadow-1: 0 1px 3px rgba(0,0,0,.10);
}
```

**CTA 규칙.** Primary = `bg-ink-900 text-white` pill 또는 radius-control, 높이 44~48. Secondary = `border-line-200 text-ink-900`. 액센트 블루는 **링크·선택 상태·"추천" 배지·포커스 링**에만. 현재 `bg-blue-600` CTA 8곳을 ink-900 으로 바꾼다.

**타이포.** Pretendard 유지. H1 40/44 700 `tracking-tight`, H2 24/32 700, H3 18/24 600, 본문 16/25.6 400, 라벨 14 500, 캡션 12. 히어로 디스플레이 48~56 에 **300 웨이트** 한 줄로 대비.

## 5. 화면별 적용

### 홈 (비로그인)
- 히어로: 한 줄 헤드라인(300 웨이트 디스플레이) + **문제 서술 인풋**("어디가, 어떻게 문제인가요? 예: 3층 화장실 천장에서 물이 떨어져요") + 아래 카테고리 chips 7개(pill). 검색창처럼 보이되 제출 시 0단계 AI 추출로 간다.
- 그 아래 **TaskRabbit 식 인기 공사 타일 6개에 "일반 범위"** 표시(공정 사전 중간값 기반, "데이터 N건 기준" 캡션).
- 신뢰 3열: 범위 확정 · 공정별 정산 · 변경 기록. 보장 금액은 실제 정책이 없으니 **쓰지 않는다**(허위 표기 금지).
- 로그인·가입 CTA 는 헤더 우측, Primary 하나만.

### 프로젝트 목록 / 카드
- 카드: 1px line-200 보더, radius-card, 쉐도우 없음. 상단 카테고리 chip + 모집 상태 chip(open=accent-50 배경, closed=canvas-50).
- 본문: 제목 18/600 두 줄 말줄임, 지역 · 마감 D-n · **예산 또는 "AI 추정 ₩X–₩Y"**, 필요 전문분야 chips, 하단 지원자 N명 · 등록 n일 전.
- 필터 바는 pill 토글(Fiverr 인기 태그 패턴), 정렬은 우측 셀렉트.

### 프로젝트 상세
- 좌 2/3: 설명 → **공정표 체크리스트 카드**(공정명 · 설명 · 수량 가정 · **일반 범위 ₩X–₩Y** · 근거 펼치기 · `conditional` 이면 "진단 후 확정" 라벨 · 범위 위반 플래그는 warn 색). 전문가 수정 행은 좌측 2px accent 바 + "[전문가 수정] 사유".
- 우 1/3 sticky: 예산 · 마감 · 상태 · Primary CTA(지원하기 / 지원자 보기) · 북마크 아이콘 버튼.

### 전문가 공개 프로필 (신뢰 스택)
- 1줄: 이름 · `★4.8 (23)` · 활동 지역
- 2줄 배지(아바타 밖): 신원 확인 · 전문분야 · **응답 1시간 내** · 완료 N건 · (스프린트 2) 공정 납기 준수율 %
- 가격 신호: 전문가가 적은 **시작가 또는 시간당 단가**. 없으면 "견적 후 안내" 표기. Houzz 처럼 가격 공백은 피한다.
- 리뷰 목록 + (A-13) 평균 별점.

### 지원 · 계약 · 정산
- 지원서: Upwork proposal 패턴(금액 · 기간 · 한 단락). 제출 후 '내 지원 현황' 카드 리스트, 상태 chip 3색.
- 계약서: 공정표를 **표 그대로** 범위 조항에. 서명은 체크박스 동의 + 시각.
- 마일스톤: 공정 1행 = 카드 1장, 상태(대기·납품 요청·승인) + 금액 · 수수료 10% · 실지급 **분해 표시**(TaskRabbit 가격 투명성). 결제 전 총액·수수료 분해를 반드시 보여준다.

### 알림
- 헤더 벨 + 미확인 점(accent). 드롭다운 리스트, 클릭 시 읽음 + 이동. 유형별 좌측 아이콘 5종.

## 6. 적용 순서 (스프린트 1 끝난 뒤, 반나절)

1. `globals.css` 에 4장 토큰 추가, `slate-*` → `ink/line/canvas` 치환 (14개 파일).
2. CTA 8곳 `bg-blue-600` → `bg-ink-900`, 액센트는 링크·선택·배지로 한정.
3. 공통 컴포넌트 3개: `Chip`, `TrustBadgeRow`, `PriceRange`(범위 + 근거 툴팁).
4. 홈 히어로를 문제 서술 인풋으로 교체 (0단계 자연어 입력과 함께).
5. 프로젝트 카드 · 상세 · 프로필을 5장 구조로.

## 7. 하지 말 것
- 보장 금액·배경조회 같은 **실제로 운영하지 않는 신뢰 요소를 UI 에 쓰지 않는다.**
- 액센트 블루를 큰 면적 배경으로 쓰지 않는다.
- 쉐도우 2단계 이상, radius 혼용(현재 lg/xl/2xl 섞임) 금지 — 토큰 3개만.
- 다크 모드는 범위 밖(시연 일관성).

## 조사 한계
angi.com · thumbtack.com · upwork.com · fiverr.com 홈은 봇 차단으로 직접 열지 못해 레이아웃 일부는 추정이다. 색·radius·폰트 수치는 공개 디자인 시스템(Thumbprint, Airbnb/Fiverr 3rd-party 토큰 분석)에서 가져왔다. Angi 공식 hex, Houzz 서체는 미확정.
